# Wine Quality — Streamlit-приложение

## Запуск приложения

**Версия Python:** 3.13

1. Создайте виртуальное окружение:
```bash
  python -m venv .venv
```

2. Активируйте его (Windows):
```bash
   .venv\Scripts\activate
```

3. Установите зависимости:
```bash
   pip install -r requirements.txt
```

4. Запустите приложение:
```bash
   streamlit run app.py
```

В приложении есть четыре вкладки: «Оценка вина», «Модельные метрики», «Пакетное предсказание», «Что выучила модель». Модель не обучается при запуске.

## Почему различаются типы кэша?

- `st.cache_resource` предназначен для долгоживущих ресурсов, например обученного пайплайна. Загруженная `joblib` модель сохраняется как **один общий объект** на сервере, без создания копий при каждом вызове.
- `st.cache_data` предназначен для данных и результатов вычислений: таблицы `test.csv`, конфигурации, вероятностей тестовой выборки и координат ROC/PR-кривых. При выдаче результата Streamlit возвращает независимую копию, уменьшая риск случайного изменения общего состояния.

Если вызвать `joblib.load` без декоратора, Streamlit при каждом взаимодействии с виджетом заново выполнит скрипт, снова прочитает модель с диска и десериализует её. Это замедляет приложение и тратит ресурсы. `get_test_scores` кэширует вероятности и не зависит от выбранного порога: при изменении порога пересчитываются лишь решения и метрики.

**Безопасность:** файл `model.joblib` должен быть доверенным — загрузка через joblib/pickle может выполнять произвольный код. Для воспроизводимости используйте совместимые версии библиотек.

**Интерпретация:** коэффициенты обученной логистической регрессии относятся к пространству после `StandardScaler`; это не причинные эффекты. После oversampling оценки вероятностей могут требовать дополнительной калибровки.
